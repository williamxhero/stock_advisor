# 通过版本化任务注册表进化未来日程

状态：superseded by ADR-0015

启动时点优化复用现有任务注册表，不引入第二套“进化日程”或按日覆盖层。`resources/schedules/tasks.json` 只提供首次安装和恢复默认时的只读种子；运行时 SQLite 中的任务模板注册表保存当前生效配置及不可变 revision。EvaluationObservatory 可以提出调整建议，但只有进化治理在动态证据门通过后，才可通过受验证的 `ScheduleRegistry` 接口晋升或回滚未来日程版本。已经准备、认领或启动的周期继续使用其冻结的日程 revision，不被后续变更改写。每次自动变更都必须记录候选、依据、原版本、新版本、生效范围和回滚条件；超出已授权可逆字段或触及质量、安全、权限和产品目标的变更仍需用户确认。
