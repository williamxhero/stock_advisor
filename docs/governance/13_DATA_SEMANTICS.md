# Data Semantics & Evidence Standard

Version: 1.0  
Last Updated: 2026-08-21  
Scope: 事件、资金、情绪、注意力、拥挤度、扩散、价格冲击、股票角色与数据质量

## 1. 基本原则

1. 只把可观察事实写成事实；推断必须标注为推断。
2. 不因供应商给出“主力”“机构”“聪明资金”标签，就把资金身份视为已知。
3. 价格和成交用于识别参与者行为痕迹，不作为脱离事件/题材/角色的独立交易理由。
4. 同一指标在点火、扩散、拥挤和退潮阶段的含义可能相反，禁止固定方向解释。
5. 数据缺失时降低置信度或停止高强度动作，不得用叙事填补数据。

---

## 2. 来源优先级

### 2.1 事件事实

1. 政府、监管、交易所、公司公告和正式文件；
2. 公司官网、业绩会材料和可靠官方渠道；
3. 权威/主流财经媒体；
4. 行业媒体与专业数据库；
5. 社交媒体、论坛和自媒体仅作线索或注意力指标。

社交媒体线索必须回查原始来源后，才能作为事件事实。

### 2.2 行情与交易数据

1. 交易所或授权实时/历史数据；
2. 主流行情终端和专属行情页；
3. 多来源一致的网页行情；
4. 单一无时间戳来源只作C级证据；
5. 搜索摘要、帖子截图、新闻中的历史价格不得冒充实时行情。

---

## 3. 事件字段

- `event_quality`：high / medium / low；综合可信度、新颖性、持续性和利润相关度。
- `novelty`：new / incremental / recycled。
- `event_half_life`：intraday / 1-5d / weeks / quarter_plus。
- `earnings_relevance`：direct / indirect / valuation_only / unclear。
- `expectation_state`：unpriced / partly_priced / highly_priced / unknown。
- `causal_strength`：direct / strong / medium / weak / label_only。

“政策支持”不自动等于高质量事件；必须说明政策层级、执行细节、受益路径和市场是否已预期。

---

## 4. 资金行为

### 4.1 可观察描述

优先使用：

- `active_buy_dominant` / `active_sell_dominant`；
- `persistent_demand` / `persistent_supply`；
- `absorption`：卖压较大但价格影响有限；
- `buying_without_progress`：买入明显但价格/广度不再推进；
- `reflow_to_core`：分歧后资金优先回到核心；
- `flow_diffusion`：资金从龙头向因果明确的相关股票扩散。

### 4.2 订单不平衡

在数据语义明确时可使用：

`Order Imbalance = (主动买入金额 - 主动卖出金额) / (主动买入金额 + 主动卖出金额)`

必须同时记录时间窗口、数据源、主动买卖判定方法和缺失情况。不同供应商口径不可直接拼接比较。

### 4.3 禁止性表述

没有直接证据时禁止写：

- “机构正在买入/卖出”；
- “主力完成吸筹/出货”；
- “庄家控盘”；
- “聪明资金确定进场”。

可以写“呈现持续性/信息型资金特征”，并明确这是推断。

## 5. 价格冲击与吸收

- `price_impact`：资金或成交变化带来的价格反应强度；必须说明窗口和方向。
- `absorption`：大量卖出压力出现，但价格跌幅有限、快速收回或相对题材仍强。
- `buying_without_progress`：主动买入/成交显著，但股价或题材广度不能继续推进。

不能仅凭“跌不动”判断吸收；还要排除停牌临近、流动性不足、涨跌停限制、指数/板块强拉和数据口径错误。

Price Reaction Surprise记录：

- 理论预期；
- 实际反应；
- 相对指数/题材/核心股票；
- 正向、负向、确认或无明显偏差；
- 后续确认时点。

## 6. 情绪与注意力

### 6.1 情绪状态

情绪不是固定的“贪婪卖、恐惧买”，重点记录变化方向和速度：

- cooling / warming / diffusion / euphoric / divergence / retreat；
- `sentiment_delta`：情绪升温、钝化或转弱；
- 龙头、容量核心、涨停结构、涨跌家数和高位股反馈。

### 6.2 注意力

可用新闻数量、搜索热度、论坛讨论、成交额、ETF成交等代理，但必须注明来源和基准窗口。

`attention_shock`只表示关注度异常，不自动表示看多或看空。注意力上升可能先推动扩散，也可能在拥挤阶段表示潜在买方接近耗尽。

### 6.3 边际效率

重点比较：

- `flow_efficiency`：新增资金强度对应的价格/广度变化；
- `attention_efficiency`：新增注意力对应的价格/广度变化。

当资金/注意力继续上升而价格和扩散不再响应时，标记`marginal_efficiency_down`，但仍需结合吸收、题材状态和核心地位确认。

## 7. 扩散与拥挤

### 7.1 扩散

真实扩散应同时考虑：

- 龙头仍有主动性；
- 容量核心获得承接；
- 上涨/大涨家数增加；
- 资金向因果明确的核心供应链或直接受益者扩展；
- 后排质量没有快速恶化。

只出现大量擦边股上涨，不能视为高质量扩散。

### 7.2 拥挤

拥挤证据包括但不限于：

- 注意力和成交极高但边际推进下降；
- 龙头巨量滞涨或买入不再推动价格；
- 核心股走弱而后排垃圾股补涨；
- 累计换手、融资、ETF或基金持仓集中度升高；
- 解禁、减持、获利盘和事件兑现增加潜在供给。

单一高换手或单一高热度不得直接定义拥挤。

## 8. 股票角色与地位变化

角色：`market_leader`、`theme_leader`、`capacity_core`、`direct_core`、`diffusion_receiver`、`follower`、`fringe_fomo`、`unclassified`。

地位变化：

- `upgrade`：从跟随/承接升级为核心，或在分歧中率先回流；
- `maintain`：相对地位和承接保持；
- `downgrade`：落后于题材核心、回流优先级下降；
- `lost`：原核心地位被明确替代或题材退潮；
- `unknown`：证据不足。

角色描述必须相对于具体题材和时点；一只股票可以在长期产业逻辑中是核心，但在当日情绪主线中不是龙头。

---

## 9. 下一批买方与潜在卖方

`next_buyer`不是具体身份猜测，而是可验证的潜在需求来源，例如：

- 尚未扩散到的同题材资金；
- 事件确认后的趋势/机构容量需求；
- 分歧后回流；
- 被动ETF/指数调整；
- 空仓资金在市场风险偏好提高后的配置。

潜在卖方包括：获利盘、套牢盘、解禁/减持、事件兑现、融资去杠杆、ETF赎回和退潮中的被动止损。

无法说明下一批买方时，不得仅凭“大家都看好”作为买入理由。

---

## 10. 数据质量和置信度

- **A**：原始/官方或明确时间戳的可靠数据；
- **B**：两个独立可靠来源基本一致；
- **C**：单一可靠来源但时间或关键字段不完整；
- **D**：陈旧、冲突无法解决或核心字段缺失。

结论置信度必须同时考虑数据质量和证据完整度。A/B级价格不能补偿事件因果缺失；高质量事件也不能补偿D级实时数据来形成高强度盘中指令。

---

## 11. 历史可审计性

- 每条状态和机会记录协议版本与数据口径版本；
- 口径升级只影响新记录；
- 不用新定义重写旧样本；
- 若历史字段无法按新口径还原，保留为空或`unknown`，不得事后推断填满。
