## 目标

不再以 Codex CLI 作为应用 LLM 底层，而以 URL 与 API key 配置直接调用 Provider API。新闻与公开资料检索可使用已配置的 SearXNG、本机浏览器扩展或静默 Playwright。

## 计划要点

- 运行时维护 Provider 配置、模型/推理路由、超时、重试与请求审计；认证材料不写入 JSON、日志正文或模型上下文。
- 研究阶段使用可验证的证据资格门：无有效证据、无合格阶段结果或 Provider 超时，都不能产出或发布伪研判。
- 隔离预览使用独立 bundle；仅通过资格门的预览才可能审批导入，失败预览不得进入正式数据库或 Exchange。
- Provider 失败需要保留真实失败轨迹，必要时在同一冻结输入下按策略降级重试，而非用旧新闻或编造正文替代。
- 工具调用仅在模型实际调度后发生；因此 Provider 未返回有效响应时，不能把未被调用的 SearXNG/Playwright 误判为检索故障。
