# 历史功能记录：统一认知伙伴与每日对话

来源聊天：`统一非H0对话与变更链路`（线程 `01a03b6a-e74b-7270-814c-f8fa9abfe832`）  
记录时间：2026-08-27  
最后已知状态：已由提交 `e711fd2 feat: unify companion cognition and daily conversation` 实施；本记录保留当时计划，非当前 canonical 规范。

## 目标

对外提供一个连续的炒股搭档；对内以统一认知入口理解所有已提交的非正式对话及 H0 的可受控事实动作，避免“聊天 AI”和“持仓解析 AI”各自理解同一用户表达。

## 计划要点

- 定时交易流程继续承担 M0、M1、M2 与 H0 的正式研判职责。
- 增加按 `Asia/Shanghai` 自然日划分的每日通用对话，周末和非交易日同样存在。
- 已发送但未提交的消息跨日迁移并保留原始时间；输入框草稿跨日、切换和重启保留，直到用户主动发送或清除。
- 每次统一认知调用产出自然语言草稿与受控动作计划；动作经确定性模块执行并返回回执后，最终回复才可声称“已更新”。
- 持仓、记忆、公开研究与工作流分别为受控能力；领域模块验证并执行，不再各自调用 LLM 重复理解用户。
- 同一持仓快照或成交在单一事务中原子提交；跨领域允许部分成功，并在回执中分别说明。
- H0 锁定后，策略路径和统一认知可读取同一不可变原文并行工作；M1 不得读取本轮 H0、统一认知回复或其派生信息。
- M2 不等待统一认知动作；后续事实若足以改变建议，只能新增判断修订，不能改写已发布研判。
- 自动提交只处理已进入待提交区的完整批次，不读取输入框草稿；计划中默认的任务前提前量为 20 分钟，并允许任务级覆盖。

## 验收边界

- 原文、命题、动作计划、动作回执和最终回复可追溯，且可幂等恢复。
- 能力型秘密在进入认知前被确定性阻断；持仓、观点与经验按相关性和时点规则使用。
- 混合表达中，用户私有事实、用户观点与外部主张分别处理；歧义仅阻塞依赖该命题的动作。
- 当前 H0 的派生信息不能泄漏进入 M1；统一认知失败不阻塞 M1。
