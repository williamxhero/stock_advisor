# Casebook

## Case 2026-08-20：金山办公（688111）— 好财报后的弱价格反应与清仓决策

### 背景
- 持仓：200股。
- 当天财报/基本面信息总体偏正面，但价格表现弱。
- 盘中从较高位置回落，临近收盘仍偏弱。
- 市场整体处于昨日恐慌后的广泛修复环境，因此“好消息 + 弱反应”具有额外负面信息。

### 当时判断
最初根据 Price Reaction Surprise，倾向于在尾盘持续弱势时清仓。

### 实际操作
- 2026-08-20：卖出200股，全部清仓。
- 收盘价附近：241.64元。

### 事后立即发现的决策问题
用户提出：金山办公存在“突然拉升”的交易特征，如果今天卖出、次日突然反包怎么办？

进一步讨论后发现：
1. 200股持仓受交易单位影响，实际上接近“全留/全卖”；
2. 原建议把“应该减仓”的信息直接映射成“全部清仓”，决策强度放大；
3. 没有在卖出前充分展示次日反包/跳空的机会成本；
4. 在组合已经通过新泉、正泰、力星降风险后，没有必要同时强制清除所有高Beta风险。

### 修正后的方法
以后对于这种二元仓位：
- 普通弱势不直接触发清仓；
- 提高清仓确认阈值；
- 14:30必须比较明日向上与向下尾部；
- 若卖出，必须提前给出重新买回条件，避免第二天因后悔追高。

### 状态
**T+1初步支持原方向，但仍待T+3/T+5。**

### T+1补录（2026-08-21）
- 收盘约240.50元，较8月20日14:30判断价241.15元约下跌0.27%，当日跌幅约0.47%。
- 没有出现担心中的次日高开反包，Good News + Weak Reaction得到第二天弱反应的初步确认。
- 这只能支持“方向判断”，不能消除原清仓决策在二元仓位和Counterfactual Check方面的流程缺陷。

需要补录：
- T+1（2026-08-21）金山开盘、10:30、收盘表现；
- T+3表现；
- T+5表现；
- 如果次日反包，是否符合重新买回条件；
- 如果继续下跌，原清仓是否在风险收益上仍然合理。

## Case 2026-08-20：新泉股份（603179）— 普涨修复日仍显著偏弱

### 背景
- 前一交易日表现极弱。
- 2026-08-20市场出现广泛情绪修复，但新泉仍明显偏弱。

### 决策
把“理论上应该修复但没有修复”视为高价值负面信息。

### 实际操作
- 卖出400股，清仓。

### D0收盘补录
- 14:30判断价：34.80元；收盘价：35.66元。
- 14:30至收盘上涨约2.47%，说明“全天相对弱势是否有预测力”和“尾盘卖出时机是否合适”必须分开验证。
- 该尾盘反弹尚不能证伪原判断，T+1/T+3/T+5相对收益仍是主要检验指标。

### 待验证
记录T+1/T+3/T+5是否继续弱于指数与相关题材，检验“修复日修不动 → 次日/短期继续相对弱”的有效性。

### T+1补录（2026-08-21）
- 收盘候选价约36.73元，当日上涨约4.79%，较8月20日14:30判断价34.80元约上涨5.55%。
- 该表现构成明显反包，对“修复日修不动 → 次日继续相对弱”形成直接反证，也显示昨日尾盘清仓存在显著机会成本。
- 但8月21日14:30保持空仓、不因卖飞焦虑追高，仍符合R-006；方向判断错误与执行纪律正确应分开评价。
- 当前公开来源的8月20日前收口径与项目D0记录存在差异，具体价格仍需用券商成交/行情记录复核；方向和涨幅结论暂不受影响。

## Case 2026-08-20：亨通光电（600487）— 急跌后的相对强承接

### 背景
- 前一交易日大幅下跌。
- 2026-08-20在指数不算强的情况下明显修复，盘中表现强于多数相关标的。

### 决策
认为其属于恐慌后出现真实承接的少数强票，允许增加风险敞口，但不追成大仓。

### 实际操作
- 当日新增买入100股。
- 收盘总持仓200股。
- 收盘价62.02元。

### 待验证
- T+1能否保持强于板块；
- 62附近是修复高潮还是新一轮承接起点；
- 如果次日高开回落，是否应把新增100股视为交易仓处理。

### T+1补录（2026-08-21）
- 收盘62.18元，较8月20日14:30判断价60.94元约上涨2.04%，绝对收益仍为正。
- 当日通信设备板块约上涨2.98%，亨通光电仅约上涨0.26%，昨日的“相对强承接”在T+1未能继续保持相对优势。
- 当前结论为“绝对承接部分成立、相对强度证据减弱”，继续等待T+3/T+5。

## 后续龙头视角案例的最低记录字段

新增案例除原有背景、判断、操作与T+N结果外，至少记录：

- `event_id` / `theme_id`；
- 事件质量：来源、新颖性、持续性、利润相关度、是否已预期；
- 题材状态：判断前、判断后及状态迁移证据；
- 股票角色：市场总龙头/题材龙头/容量核心/直接受益核心/扩散承接/普通跟随/擦边；
- 龙头地位变化：升级/维持/下降/失去；
- 资金、注意力、拥挤度、价格冲击与吸收证据；
- 理论预期、实际反应和Price Reaction Surprise；
- 下一批潜在买方与潜在卖方；
- 当时可见的替代核心；
- 买入/持有/加仓/减仓/清仓/弱换强理由；
- 明确失效条件与Counterfactual；
- T+1/T+3/T+5、MFE、MAE及相对题材/指数表现。

不得只保存“这只股票后来涨了/跌了”的结果。案例的重点是还原当时的主线、地位和可获得证据。
