# ChatGPT 定时任务邮件契约

Windows 客户端不依赖某个特定的发件人，只依赖标题和正文，因此邮件可以由 ChatGPT、Make、n8n 或其他中间层发出。

## 标题

每个任务必须生成一个且仅一个标题：

```text
[ChatGPTTask][A股][HH:mm] 任务名称 yyyy-MM-dd
```

固定节点：

| 时间 | 任务名称 |
| --- | --- |
| 09:00 | 盘前机会发现 |
| 09:45 | 开盘异常发现 |
| 10:30 | 趋势确认 |
| 14:30 | 操作决策 |
| 15:20 | 收盘复盘 |

## 正文

正文直接使用完整 Markdown 结果，不要只发送“任务已完成”通知。建议至少包含：

```markdown
# 任务名称

## 市场状态
...

## 持仓操作
...

## 新增机会
...

## 风险
...
```

## 幂等规则

客户端以 Gmail message id 去重。同一封邮件反复轮询不会重复入库；如果中间层重发了一封新邮件，它会被视为一条新的结果，同一节点展示接收时间最新的一条。
